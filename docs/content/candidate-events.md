# Candidate time events (how long ago)

One brick per year. Years are counted back from 2026. "About" means the number is rounded or the date is a range; anything without "about" is a known date. Each item has a card line written for an eight-year-old and, where it fits, a footer phrase ("before …"). Tick the box to keep an item, or delete its lines. Items already on the stack are ticked.

Personal rows use the profile (age, and possibly two new fields).
